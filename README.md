Page01 - Bandeja de entrada
Simula una aplicación de correo electrónico. Muestra una lista de mensajes recibidos. Incluye información del remitente, asunto y contenido del mensaje. Presenta una versión clara y otra oscura de la bandeja de entrada. Incluye iconos de menú, búsqueda y mensajes destacados. Utiliza un diseño responsive para adaptarse a diferentes tamaños de pantalla.

Page02 - Playas y ciudades del Perú
Muestra un listado de las diez mejores playas del Perú. Cada playa incluye nombre, ubicación e imagen. Genera las tarjetas de playas mediante JavaScript. Muestra un listado de diez ciudades del Perú. Cada ciudad incluye temperatura, velocidad del viento y humedad. Presenta alertas de clima extremo. Organiza la información en tarjetas responsive.

Page03 - Tienda de plantas
Simula una tienda online de plantas y accesorios. Incluye categorías como plantas, macetas, ofertas, suscripciones y cuidados. Muestra productos recién llegados. Cada producto incluye imagen, nombre y precio. Incluye botones para agregar productos al carrito. Presenta opciones de registro, inicio de sesión, búsqueda y carrito. Incluye información de contacto, horarios y enlaces útiles. Utiliza un diseño adaptable a diferentes dispositivos.
